# AGENTS.md

Agent instructions for this repository live in **[`CLAUDE.md`](./CLAUDE.md)**.

That file is the single source of truth: run and verify commands, the standing
invariants, approval boundaries and clinical risk categories, DOM traps,
vocabulary rules, and the Git workflow. It applies to any coding agent working here, not only Claude Code.

Keeping one file avoids the failure mode this project has already seen with
documentation — two copies that drift until neither can be trusted.
